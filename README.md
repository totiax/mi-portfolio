# Matias Skuarok — Portfolio

Portfolio de Matias Skuarok, desarrollador full-stack freelance en Villa Carlos Paz, Córdoba.

Hecho con Next.js, React, TypeScript y GSAP.

## Desarrollo

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).

## Editar contenido

Proyectos, perfil, stack y soluciones están en `src/data/portfolio.ts`. Las capturas de proyectos van en `public/portfolio/` (2400×1200, JPG).

## Deploy

Se publica en Netlify automáticamente con cada push a `main`.
